# My K-pop Collection

## Project Description

My K-pop Collection is a desktop application that helps K-pop fans organize both their favorite idols and their K-pop merchandise collections. Users can manage information about their favorite idols while also keeping track of collectible items such as albums, photocards, lightsticks, and other official merchandise. The application also allows users to maintain a wishlist of items they hope to collect in the future.

This application is intended for K-pop fans and collectors who want a simple way to organize their collections and favorite idols. I am interested in this project because I enjoy listening to K-pop and following different idol groups. I also think it would be fun to combine one of my hobbies with the object-oriented programming concepts that I learn in CPSC 210.

## Main Features

- Manage a list of favorite K-pop idols
- Manage a personal K-pop merchandise collection
- Keep track of a wishlist for future collectibles
- Store information about collectible items, including albums, photocards, and other merchandise

## User Stories

- As a user, I want to be able to add a collectible item to my collection.
- As a user, I want to be able to view all collectible items in my collection.
- As a user, I want to be able to add a favorite idol to my idol list.
- As a user, I want to be able to view detailed information about a favorite idol.
- As a user, I want to be able to add a collectible item to my wishlist.
- As a user, I want to be able to move a collectible item from my wishlist to my collection after obtaining it.
- As a user, I want to be able to update the condition or notes of a collectible item.
