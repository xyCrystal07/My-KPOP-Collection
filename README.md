# My K-pop Collection

## Project Description

My K-pop Collection is a desktop application that helps K-pop fans organize both their favorite idols and their K-pop merchandise collections. Users can manage information about their favorite idols while also keeping track of collectible items such as albums, photocards, lightsticks, and other official merchandise. The application also allows users to maintain a wishlist of items they hope to collect in the future.

This application is intended for K-pop fans and collectors who want a simple way to organize their collections and favorite idols. I am interested in this project because I enjoy listening to K-pop and following different idol groups. I also think it would be fun to combine one of my hobbies with the object-oriented programming concepts that I learn in CPSC 210.

## Main Features

- Manage a list of favorite K-pop idols
- Manage a personal K-pop merchandise collection
- Keep track of a wishlist for future collectibles
- Store information about collectible items, including albums, photocards, and other merchandise

## User Stories

- As a user, I want to add a favorite idol.
- As a user, I want to remove a favorite idol.
- As a user, I want to view my favorite idols.
- As a user, I want to add a collectible item.
- As a user, I want to remove a collectible item.
- As a user, I want to view my collectible items.
- As a user, I want to add an unowned collectible item to my wishlist.
- As a user, I want to view my wishlist.
- As a user, I want to have the option to save the entire state of my application to file so that I do not lose my favorite idols, collection, and wishlist.
- As a user, I want to have the option to load the entire state of my application from file so that I can continue from where I previously stopped.

# Instructions for End User

- You can view the panel that displays favorite idols by clicking "Show Idols".
- You can add a favorite idol by clicking "Add Idol".
- You can add a collectible item by clicking "Add Item".
- You can locate the visual component on the right side of the GUI.
- You can save the state of the application by clicking "Save".
- You can reload the state of the application by clicking "Load".
